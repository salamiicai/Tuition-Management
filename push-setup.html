Create push notification keys

Creates a one-time key pair in your browser. Nothing is uploaded.

1. PUBLIC key → js/config.js (VAPID_PUBLIC_KEY) and Worker variable VAPID_PUBLIC

2. PRIVATE key → Worker Secret VAPID_PRIVATE_JWK

Keep this private. Never put it in your website files or share it. If you lose it, just generate a new pair (students will need to tap "Turn on notifications" again).
